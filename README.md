# TextSeek

## Install

<a href="https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/ascolith/TextSeek"><img src="designs/badges/badge_obtainium.png" alt="Get it on Obtainium" height="80"></a>

The badge opens [Obtainium](https://github.com/ImranR98/Obtainium) with TextSeek ready to add,
and Obtainium then keeps it updated. Or download the latest `TextSeek-<version>.apk` from
[Releases](https://github.com/ascolith/TextSeek/releases) and open it on your phone.

### Verify the signing certificate

Release APKs are signed with this certificate. Check it with
[AppVerifier](https://github.com/soupslurpr/AppVerifier), or with
`apksigner verify --print-certs <apk>` from the Android SDK build-tools:

```
com.ascolith.textseek
7A:60:5D:15:81:00:A7:C9:CF:46:1B:7C:7F:4A:FD:4D:14:AB:4A:DE:DA:A7:C1:50:E7:55:28:99:7F:60:23:6C
```
